# Double Pupil 0.4 使用说明

## 启动

1. 将软件压缩包完整解压到 Windows 本地目录（建议 Windows 10/11、64 位）。
2. 双击 `DoublePupil.exe`。不要只复制 EXE；`resources`、DLL 等配套文件必须保留。
3. 不需要安装 Python、Node.js、Qt、WSL 或数据库，也不需要打开浏览器。

程序使用 `%LOCALAPPDATA%\Sentinel\data` 保存设置、项目和调查数据，这是兼容历史版本的数据目录。同一台电脑会继续读取已有配置；另一台电脑首次启动为 Demo，需自行填写连接配置。发行包不含现场 API Key、数据库或原始流量证据。

更新前退出旧程序并备份上述数据目录。解压新版本到新目录后启动；不要同时启动多个版本操作同一数据目录。删除软件目录不会自动删除用户数据。

## 首次配置

打开左侧“设置”，按二级目录配置，每个分区分别保存：

- **AI 模型**：选择兼容 API，填写 Base URL、模型名称、API Key。DeepSeek 官方地址为 `https://api.deepseek.com`，模型名称以账户实际可用模型为准。思考模式“自动”会对 DeepSeek 关闭思考，避免正文额度不足。空白密钥保存表示保留已有密钥。
- **XDR 平台**：选择 Live，填写平台地址与授权码/AK/SK，使用连接测试确认可用。现场平台为 `https://172.20.0.140`。其他电脑需能路由到相应内网。自签名证书可配置可信 CA；TLS 校验选项与现场环境对应。
- **智能体执行 / Skills / RAG / 修复**：设置执行参数、导入技能和知识文档，启用后参与调查。导入并不代表允许任意远程执行命令。
- **工作与输出目录**：选择源码导入目录与报告目录。更改工作目录不会搬迁已有项目。
- **威胁情报**：选择 CISA 或 NVD，设置同步间隔并启用；NVD API Key 可选。定时任务仅在程序运行期间执行，关闭期间不运行。同步失败保留旧数据并显示错误。

右上角支持日间、夜间、跟随系统。

## 资产与源码

“资产”默认显示左侧列表和大区域拓扑；点击“新增”才显示登记表。登记 IP、名称、标签、环境、负责人，绑定代码项目及 Web 服务地址；编辑和删除在选中资产后操作。拓扑连线表示逻辑分组，不是自动发现的物理链路。

“发现内网资产”可输入私有 IPv4/CIDR 和端口；单次最多 /24、12 个端口。发现结果按 IP 入库，保留已登记名称和项目。未发现开放端口不代表主机不存在。

在“代码”中导入本地目录、ZIP 或受支持的公开 Git 仓库，再运行扫描。支持 Python Bandit 和有限的 PHP SQL/命令注入语法分析，不是全语言完整 SAST。

现场 Pikachu 位于 `http://172.20.0.252:12348/`，部署路径前缀为 `/`。Pikachu 源码与容器不随本软件发行；在另一台电脑测试时需重新导入自己的源码并登记资产。

## 调查与报告

1. 在“事件”同步 XDR，选择事件并绑定实际部署的代码项目。
2. 启动 AI Investigation，等待工具执行完成。
3. 在“调查画布”查看攻击入口、候选漏洞位置、代码快照和证据。
4. 在“调查思维链”查看执行节点、时间、状态与证据引用，并导出 Word（`.docx`）、Markdown 或 JSON。

“调查思维链”展示可审计的执行记录，不展示模型内部推理。AI 结论是辅助判断；静态关联并不证明攻击成功。现场 Pikachu 已关联到 `vul/sqli/sqli_str.php:29`，但未核对容器与源码哈希，关联仍标注为候选。

## 离线体验

在设置中使用 Demo XDR 和 Mock 模型，选择演示 SQL 注入事件与 `Shop API · 演示项目` 运行调查。静态扫描会实际执行，AI 输出明确标为离线规则模式。真实模型、XDR 和情报更新均需要相应网络连接。

## 修复范围与故障排查

- SSH 修复只支持实现的特定 SQLite/Python 配方，要求资产授权、主机指纹与源码快照检查；有备份和回滚机制。本版没有实现 Pikachu PHP 的通用自主修复。
- XDR 连接失败：核对内网可达性、授权有效期、系统时间及 TLS 设置。
- AI 无正文或超时：核对模型名称、密钥与额度；DeepSeek 使用自动/关闭思考，必要时提高超时或输出额度。
- 情报同步失败：查看错误与最近成功时间，网络恢复后重试；旧数据继续可查。CISA 为已利用漏洞目录，NVD 为 CVE 发布动态，两者不是本机资产的漏洞扫描结果。
- 不能启动：确认完整解压、未从 ZIP 内直接运行，保留配套文件。Windows 提示发行者未知时，本包尚未做商业代码签名，可先核验随附交付清单中的 SHA-256。

详细功能与验收范围见 `docs/DOUBLE_PUPIL_V04.md`、`docs/ACCEPTANCE.md`；许可证见根目录许可文件及 `THIRD_PARTY_NOTICES.md`。
