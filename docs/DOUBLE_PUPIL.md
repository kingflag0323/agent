# Double Pupil 0.3

Windows Electron 桌面版。保留调查画布及日间、夜间、系统主题；名称变更不迁移数据库，以免丢失现场连接配置。旧 `%LOCALAPPDATA%\Sentinel\data` 是兼容数据目录名，不是界面品牌。

## 资产和授权

资产页支持新增、搜索、修改、删除，记录 IP/域名、负责人、环境、说明、绑定代码项目。事件 IP 唯一匹配资产且事件未手动绑定时，自动填入代码项目。

SSH 配置保存本机私钥**路径**，不复制或展示私钥内容。当前支持 Linux/POSIX 目标，固定 SHA256 主机公钥指纹，禁用自动接受指纹、SSH Agent 和默认密钥搜索。连接测试仅打开 SFTP 并读取规范目录。不能用 XDR API 授权码代替 SSH 密钥。

资产的“自主 SSH 修复”开关是一项明确授权：仅该主机、该项目、逐项列出的 Python 文件，且必须配置远程验证命令参数。默认关闭，未配置任何现有设备的 SSH 写入授权。本次交付不对 XDR 设备执行修复。

## 当前自主修复范围

目前仅提供 `sqlite-parameterization-v1`：将明确 `sqlite3.connect` 连接中的 `SELECT … WHERE field = ` 加单个变量拼接改为 `?` 及参数元组。必须是可识别的相邻赋值/执行模式，不处理引号包裹输入、标识符拼接、复杂表达式、多次使用变量、其他数据库驱动或任意模型补丁。SQL 方言不明时停止。命令注入等发现继续提供建议，尚未支持自动写入。

新调查完成时自主触发，也可在调查画布的“研判与复核”中执行已授权修复。需要：真实事件、唯一 IP/项目绑定、完成调查、证据复核通过、唯一高置信且位于授权文件清单的漏洞候选。静态高置信不是攻击成功证明。

执行步骤：生成完整文件差异 → AST 语法检查 → 实际 Bandit 复扫（目标 B608 消除、无新增规则） → SSH 指纹校验 → 远程文件内容与扫描快照严格比对 → 备份并校验 → 原子替换 → 运行资产配置的验证命令。命令使用参数数组、shell 引号转义，模型及 Skills 不能修改它。代码文件本身的业务行为仍需项目测试覆盖。

远程文件不符、路径穿越、符号链接、非普通文件、特殊权限、文件所有者/组不一致或缺少原子重命名支持时拒绝部署。远端并发写入仍需要运维协调；SFTP 无法提供对外部进程的事务锁。

验证失败尝试恢复原文件；远程验证命令可能产生文件之外的副作用，其回滚不在此配方范围。网络中断、服务异常退出或并发文件变化时保留 `recovery_required`，阻止该资产后续自动修复，必须人工核实原文件/备份及服务状态。不会把断连误报为修复成功。此版本没有通用服务重启、防火墙处置或任意系统补丁能力。

智能体页的修复记录保留差异、前后哈希、验证扫描 ID、备份路径、验证输出及最终状态。记录位于本机数据库；备份位于目标原文件相邻路径、权限 0600。

## Skills 与 RAG

原生文件选择框支持导入 `.md/.txt/.json`，单份最大 64 KB，每类最多 100 份，可修改、启停、删除。

- Skills：作为调查参考文本，最多 5 份启用文档，每份前 6000 字。不执行 SKILL.md 引用的脚本或安装依赖，也不是可任意运行命令的插件沙箱。
- RAG：本地中英文词法检索（英文词及中文双字），900 字步长、1100 字片段，引用前 5 个命中。不是向量嵌入检索。可在 UI 测试查询。
- 调查保存实际使用的文档 ID、片段、内容 SHA256；详情在画布“研判与复核”。导入内容作为不可信参考数据，不能覆盖模型系统约束或修复授权。
- 模型和执行限制仍在“设置”页。未配置外部模型时显示 Mock；参考检索照常执行，但不声称已调用真实模型。
